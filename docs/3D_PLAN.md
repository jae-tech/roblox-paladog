# 3D 동행 전투 전환 (2026-10-16)

최신 사용자 지시가 `REMAKE_PLAN.md`의 2D 화면 재현보다 우선한다. 목표는 **식량 코스트로 용병을 소환하고, 플레이어가 3D 전장에서 직접 이동·마법 공격을 하며 용병들과 함께 전진**하는 것이다. 마법은 별도 마나를 쓴다.

## 유지 / 변경

- 유지: 원작 데이터·소환 식량/쿨·용병 자동전투·마나/무기·성장·서버 권한·슬롯/정산 1회·lease. 기존 R1~R5를 제거하거나 테스트를 약화하지 않는다.
- 변경: 평면 GUI 전장을 실제 Workspace의 3D 던전/개체/투사체로 교체한다. 뒤에서 전방을 바라보는 추적 카메라, W/S 전진/후퇴·A/D 횡이동, 1~9 소환, Q/E/R 또는 전장 클릭으로 마법. 터치 조작부는 별도 버튼이다.
- 3D 전투는 서버의 선택 옵션이다. 기존 모드의 검증 기준선은 옵션 없는 순수 전투로 보존한다. 공간 옵션에서는 X/Z 거리·이동·탄·오오라를 서버가 판정하고, 용병은 영웅 가까이에 나타나 함께 전진한다. 특수 모드 고유의 고정 이동/라인/점프 규칙은 유지한다.
- 첫 전환은 개인 소유 전장이다. 협동 플레이·새 자유탐험/퀘스트 시스템·새 결제·외부 에셋·서바이벌 신규 구현은 이번 범위에 추가하지 않는다.
- 단위는 서버 px·30Hz 그대로, 렌더링 1px=0.12stud, 통로 횡방향 ±90px. 이는 3D 조작을 위한 신규 설계값이다. 수치 생성 파일은 직접 바꾸지 않는다.

## 구현·검증 순서

1. 3D 공간/입력 계약과 비용·쿨·권한·결정론 회귀 추가.
2. Battle/MatchService/Protocol에 선택적 공간 이동·거리 판정 연결. 원작 모듈은 재사용한다.
3. 3D 던전·원본 도형 모델·투사체·카메라, WASD/클릭/마법/HUD 연결. renderer/입력/카메라 종료 시 원상 복구.
4. CLI 공간 suite + R1~R5/P2/P8 관련 회귀, 정적 분석·lint·format·build·출시 감사.
5. 승인 Studio에서 실제 출전→WASD→소환→함께 전진→마법/피해→결과/로비를 확인한다. 메모리 fixture와 실제 입력 결과는 구분한다. 실 저장/게시/업로드 없음. 실기기 멀티터치는 별도 제한이다.

완료 기준: 실제 3D 모델과 추적 카메라로 영웅·용병·적을 볼 수 있고, 서버 권한으로 두 축 이동/식량 소환/마나 시전/용병 전투가 작동한다. 정산 중복 지급과 타인 입력이 차단되고, 로비 복귀 시 3D 인스턴스/카메라가 정리된다.
