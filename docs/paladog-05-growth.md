### B3. iNewHP/iNewAP 는 "대체(replace)" [확인]
```java
// AppDelegate.java:779-785 (CreateNpc, 팔라독 유닛)
```

- 기본 DB 행(207~)의 `iMaxHP/iAtPwr` 는 **덮어써짐**. 그 외(이동속도, 사거리, 공격딜레이, 마나, 쿨타임, 스킬)는 기본 DB 행 값 유지. 예: 쥐 기본 iMaxHP=300 이지만 실제 L1 HP=100, 곰 기본 1000 → 실제 1200.
- 다크독 토템도 동일(행 534~) — `AppDelegate.java:1182-1189`.
- **[확인 — 바이트코드 검증]** JADX 일반 출력은 `lc_iDBRow = 0`으로 보이지만(디컴파일 손실), JADX `-m fallback`(원시 바이트코드) 출력에서 `row = (gkGameKind != 2) ? max(L-1, 0) : 0` 임을 확인함 — `GameManager.GetTTMAttackPower/GetTTMHPMax`, `AppDelegate`의 유닛 생성부(`+354`, `+534` 두 곳). 즉 **캠페인 = 레벨 L 행을 그대로 사용, 서바이벌 = L1 행 × (1 + 0.2×(L−1))**.
- [확인] 서바이벌 배율 `fSVVUnitUpgradeMulVal = GetDBInfoS(142).m_fDBVerStage` = **0.2** — `GameManager.java:3977`, `stage.txt [142] fVer__=0.2`.
- [확인] UI 공격력 표시는 AP×10 (`SetNumCurAtk(m_iLvUpNewAP * 10)`) — `UnitUpgradeLayer.java:1033`. 실제 전투값은 AP 그대로.
