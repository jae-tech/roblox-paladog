# Paladog 게임 시스템 명세서 — 인덱스

Roblox 리메이크를 위해 `reference/paladog.apk`를 정적 분석한 결과를 정리한 문서 묶음이다. 코드를 실행하거나 런타임을 관찰하지 않았으므로, 모든 결론은 **정적 증거(디컴파일 코드, 패키지 내 데이터 파일)**에 근거한다.

## 4. 표기 규칙

- **[확인]**: 디컴파일 코드 또는 패키지 내 데이터에서 직접 읽은 사실.
- **[추정]**: 정황에 근거한 해석. 구현 전에 재검토하거나 기획 판단으로 정해야 한다.
- 근거는 JADX 출력 `sources/` 기준 `파일:줄` 형식이다. 줄 번호는 JADX 1.5.1 기본 옵션 출력 기준이므로, 다른 버전이나 옵션으로 디컴파일하면 줄 번호가 달라질 수 있다.
- `db.txt [n]` = `pdw_db.xml`의 n번째 `<Data>`(0부터), `stage.txt [n]` = `pdw_db_stage.xml`의 n번째. 게임 코드의 `GetDBInfo(n)`·`GetDBInfoS(n)`와 같은 인덱스다(행 순서가 곧 ID, `DB/MyXMLReader.java:49-60`).

## 5. 핵심 사실 요약

1. **시간·거리 단위** [확인]: 이동속도는 px/초, `fAtDly`·쿨타임은 초, 공격 타격 시점 `iAt1Fr`은 애니 프레임(1/30초) 단위다. 따라서 Roblox에서는 px→stud 환산 비율 하나만 정하면 거리 값을 일괄 변환할 수 있다.
2. **자원 2종** [확인]: 유닛 소환은 **식량**을 쓴다(DB 컬럼명은 `iMana_`이지만 차감은 식량에서 일어남). 메이스·검은 **마나**를 쓴다. 두 자원 모두 전투 시작 시 0이다.
3. **레벨표는 대체 방식** [확인, 바이트코드 검증]: 유닛 HP·공격력은 기본 행(207~215)을 쓰지 않고, 레벨표 `354+(유닛-1)×20+(L-1)` 행 값으로 덮어쓴다.
4. **데미지** [확인]: 방어력 개념이 없고 배율만 곱한다. 오오라, 방어 스킬, 장비, 난이도(적 HP만)가 배율로 들어간다. 크리티컬·회피는 다크독 모드에만 있다.
5. **오오라** [확인]: 영웅 주변 X거리(팔라독 75+25·Lv)와 같은 라인 안의 아군에만 적용된다. 오오라 밖의 아군 유닛은 스킬을 발동할 수 없다.
6. **적 스폰** [확인]: [min, max+0.9]초 간격으로 생성한다. `iUCnt_`마리 단위로 느린 구간과 빠른 구간이 번갈아 무한 반복된다. U5는 확률이 아니라 (P5+1)마리마다 1마리씩 나온다. 챕터별 스탯 배수는 없다.
7. **승패** [확인]: 아군 본진은 없다. 영웅이 죽으면 패배하고, 승리 조건은 모드별로 다르다(적 본진 파괴, 보스 처치, 60킬, 마차 호위, 타워 점수, 점프 완주).
8. **성장** [확인]:
   - 영웅 레벨은 누적 EXP가 Lv²×100 이상일 때 오른다. 레벨이 오를 때 받는 것은 스킬 1포인트뿐이며, 후보 3개 중 1개를 고른다.
   - 유닛 강화는 골드로 하고 L20이 최대다.
   - 장비 강화는 젬 (등급+1)×2개로 하며 항상 성공한다. 등급 상한은 챕터 진행에 따라 올라간다.
9. **보상** [확인]:
   - 스테이지 DB의 클리어 보상(`iCrRwd`)과 클리어 시간(`iCrSec`)은 **코드에서 쓰이지 않는다**.
   - 실제 보상과 별은 `quest.xml`의 퀘스트 3개로 정해진다.

## 6. Roblox 이식 시 권장 사항 [추정 — 설계 제안]

아래는 원작 사실이 아니라 분석 결과를 바탕으로 한 구현 제안이다.

- **데이터 이식**: `pdw_db.xml`·`pdw_db_stage.xml`·`quest.xml`을 ModuleScript 테이블로 옮긴다. 원작이 "행 순서 = ID"를 쓰므로 순서를 보존하거나 명시적 ID를 붙인다. 레벨표 라벨 5/6이 뒤바뀐 문제(명세 05 B2)에 주의한다.
- **좌표계**: 원작은 2D 횡스크롤이다. 전장 폭은 1024px, 적 본진은 x=904, 일반 모드는 사실상 단일 레인이다. Roblox에서는 X축 한 줄 레인에 Y를 깊이 연출용 지터로 쓰면 원작 판정(1차원 |dx| 비교)을 그대로 재현할 수 있다.
- **서버 권한**: 원작의 세이브 암호화(WCEncrypt+Base64)와 안티치트는 Roblox에서는 서버 권한 + DataStore로 대체한다. 계정 공통(젬·업적)과 슬롯별(골드·레벨·유닛) 2계층 구조는 유지할 만하다.
- **원작 버그 의심 동작**: 아래 항목은 그대로 재현할지 기획에서 결정해야 한다.
  - 행운의 반지 /100 이중 적용
  - 버서커 오오라가 투사체에만 걸림
  - 지옥 난이도에서 적 HP 배수 1.0
  - 15분 초과 시 골드 1·EXP 0
  - 퀘스트 보상 반복 지급
- **제외 대상**: 결제, 소셜(Kakao/Facebook/LINE/QQ), 푸시는 리메이크 범위 밖이다.
