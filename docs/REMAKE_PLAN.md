# 원작 재현 확장 계획 (REMAKE)

2026-10-16 사용자 지시: "팔라독이랑 똑같이 만들어. 스테이지부터 용병이랑 UI 같은 거 전부."

- **재현 범위**: 시스템·수치를 원작과 같게 한다. 원작 이름·그림·로고·사운드·대사는 복제하지 않고 외형은 오리지널로 만든다.
- **모드**: 팔라독 캠페인 120, 다크독 캠페인 120, 서바이벌을 모두 만든다.

이 문서는 MVP 범위(PRD·IMPLEMENTATION_PLAN, SHA 고정)를 확장한다. MVP 설계 문서 6개는 수정하지 않는다. 충돌하면 이 문서가 우선한다. 원작 사실의 정본은 `docs/paladog-*.md` 7개다(수정 금지). 아래 `[추정]`은 원작에 근거가 없어 설계로 정한 값이며, `data/remake/design.json`에 결정 ID와 함께 기록한다.

## 1. 재현 원칙

| 구분 | 원작과 같게 | 오리지널로 대체 |
|---|---|---|
| 규칙 | 상태머신, 데미지·오오라·넉다운·빙결·관통, 모드별 승패, 스폰 알고리즘, 성장 공식 | — |
| 수치 | 부록 A1~A14 전체(유닛·토템·적·보스·투사체·장비·레벨표·스테이지 241행) | 원작에 없는 값만 `[추정]` |
| 이름 | 역할(쥐=값싼 근접, 토끼=궁수 …) | 표시 이름 전부(영웅 2명, 용병 9, 토템, 적 40, 보스 13, 무기·장비) |
| 그림·소리 | 화면 구성 흐름(로비→스테이지 선택→전투→결과, 하단 이동·소환·무기 버튼) | 모델·UI 그림·아이콘·색·효과음 |
| 제외 | 결제(IAP), 소셜(친구·랭킹 서버), 푸시, 디버그 함수 | 젬 획득은 업적·서바이벌·보스 드롭으로만 |

원작 버그 의심 동작(인덱스 §6)은 기본적으로 **원작대로 재현**하고 결정 ID로 남긴다. 예외는 서버 경제를 깨는 것뿐이다. 퀘스트 보상 반복 지급은 원작대로 허용하지만, 같은 전투 결과로 두 번 받는 것은 막는다(정산 1회).

## 2. 엔진 결정

- **단위**: 원작 px·초를 그대로 쓴다. 전장 폭 1024, 적 본진 x=904. 렌더링에서만 px→stud(0.05)로 바꾼다.
- **틱**: 고정 30Hz(1틱 = 1/30초)로 원작 애니 프레임(1/30초)과 맞춘다. 이 틱을 원작 가변 dt 대신 쓴다. 정수 틱 결정론을 유지하고 `digest`로 검사한다.
- **난수**: 경기마다 seed가 고정된 단일 RNG로 원작의 `rand()%N` 호출을 같은 의미로 재현한다.
- **애니 길이**: 공격 주기는 애니 길이 + `fAtDly`다. 원작 문서에 프레임 수가 없는 캐릭터는 `max(타격프레임+4, 10)`프레임으로 정한다 `[추정 D-ANIM-01]`.
- **권한**: 서버 권한·Remote 프로토콜·lease 저장 구조는 MVP 것을 유지하고 확장한다. 클라이언트는 입력과 표시만 담당한다.
- **기존 MVP 시뮬레이션**: `src/server/Simulation/*`과 그 테스트(P3/P4/P6/P9 전투 부분)는 R3에서 새 엔진으로 바꾼 뒤 제거한다. 보안·저장·중복 보상 테스트(P2/P7/P8/P9)는 새 프로토콜로 옮긴다. 삭제하지 않는다.

## 3. 단계 (R0~R7)

각 단계는 브랜치 `rN-*`에서 커밋하고 로컬 main에 ff 병합한다. 테스트 정책(AGENTS.md)을 그대로 따른다. 구현 중에는 해당 suite와 정적 분석만 돌리고, Studio는 R4·R7에서만 쓴다.

| 단계 | 내용 | 핵심 테스트 |
|---|---|---|
| R0 데이터 | 부록 표 전체 → `data/remake/db.json`, 설계값 `design.json`, 생성 Luau `src/server/Config/Remake/*`·`src/shared/RemakeCatalog.luau` | 행 수·키 값 golden, 재생성 diff0 |
| R1 전투 코어 | 팔라독 일반 스테이지: 영웅 이동, 식량·마나·HP 재생, 유닛 9종(스킬·오오라 포함), 적 1~40, 본진·50% 러시, 투사체(직선·관통·포물선·빙결·독), 메이스 11종, 처치 보상, 레벨업 선택 | `tests/unit/R1.luau` 공식별 단위 + 결정론 |
| R2 특수 모드 | 보스 스테이지와 보스 10종 패턴, 운명(박스), 목마 호위, 타워(5라인·점수), 난이도 4단계 | `R2.luau` 모드별 승패 |
| R3 성장·서버 | 프로필 v2(계정+슬롯3), 스킬 트리 23, 유닛 해제·L20, 장비·인벤토리·드롭·상점·강화·젬 상점, 퀘스트·별, 업적, 120스테이지 해금. MatchService를 새 엔진으로 교체, MVP 시뮬 제거 | `R3.luau`: 정산 1회·권한·저장 무결성·구매 경합 |
| R4 클라이언트 | 전투 HUD(이동·소환 9·무기 3·식량/마나/HP·본진 HP·일시정지·레벨업 선택), 로비(메인·슬롯·스테이지 선택 5페이지·유닛 강화·장비/상점·스킬·업적·결과), 모든 개체 표시 | CLI 뷰모델 + Studio 실제 플레이 |
| R5 다크독 | 영웅2·토템 9(외침·가시·변신 포함)·검 11·부적·투구/갑옷/신발·스킬 24·크리/회피·적 디버프 오오라, 다크독 캠페인(교체 21스테이지), 던전(함정), 목마 파괴, 멧돼지 점프(오리지널 맵) | `R5.luau` |
