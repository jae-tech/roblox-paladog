# PRD — 등불 원정 (가칭)

문서 버전: 1.0 · 작성일: 2026-10-15 · 상태: **설계 기준선 / 게임 미구현**

## 1. 목적과 읽는 순서

Paladog에서 관찰된 **자원 배분 → 병력 소환 → 전선 형성 → 영웅의 위치·스킬 개입 → 성장**이라는 구조를 참고해, 새로운 세계관의 Roblox 2.5D 횡스크롤 전략 액션 게임을 만든다. 원작 복원·동작 동등성은 목표가 아니다. 이름·실루엣·서사·UI·음원·코드는 새로 만든다.

이 문서의 요구 ID `R-*`, 테스트의 `T-*`, 작업의 `P*`를 서로 연결한다. 상세 기준은 다음과 같다.

| 문서 | 정본 책임 |
|---|---|
| [ARCHITECTURE](ARCHITECTURE.md) | 시스템 의존성, 권한, 시간·네트워크·저장 처리 |
| [DATA_MODELS](DATA_MODELS.md) | ID, 스키마, MVP 수치, 불변식 |
| [ASSET_PIPELINE](ASSET_PIPELINE.md) | 근거 수치 변환, 출처 추적, 오리지널 에셋 |
| [IMPLEMENTATION_PLAN](IMPLEMENTATION_PLAN.md) | 순서, 파일 소유권, 완료 게이트 |
| [TEST_PLAN](TEST_PLAN.md) | 테스트 ID, Studio MCP 절차, 증거·미실행 구분 |

규칙 충돌 시 권한·저장은 ARCHITECTURE, 수치는 DATA_MODELS가 정본이다. 요구 범위를 바꾸는 변경은 PRD도 함께 갱신한다. 문서의 경로 중 기존 분석 7개와 이번 6개 산출물 이외는 **향후 생성할 경로**이다.

## 2. 근거 수준과 전체 분석 검토

- **[문서확인]**: 제공된 정적 분석 문서가 코드·데이터로 확인했다고 보고한 사항. 이번 작업에서 APK/JADX를 다시 실행해 독립 검증한 뜻은 아니다.
- **[추정]**: 원문 추정, 미추적 경로, 의도 해석. 원작의 규칙으로 확정하지 않는다.
- **[충돌/미확정]**: 문서끼리 상충하거나 관찰이 부족한 사항. 자동 수치 반입을 금지한다.
- **[신규결정]**: 이 프로젝트가 선택한 규칙. 원작에 존재한다는 주장이 아니다.
- **[플랫폼확인]**: 공식 Roblox/Rojo 자료로 확인한 API 특성. 링크와 조회일을 붙인다.

## 3. MVP 제품 경계 [신규결정]

### 3.1 플레이 경험

플레이어는 등불 탐험가와 작은 기계 동료들을 지휘하여 폐허의 신호 핵을 파괴한다. 영웅을 전선 가까이에 둘수록 아군 지원장(+10% 피해)을 줄 수 있지만 사망 위험이 커진다. 개별 유닛은 직접 조작하지 않는다.

`로비(성장) → 스테이지 선택 → 준비/실행 저장 → 자원 축적·소환·개입 → 종결 → 서버 보상 확정·저장 → 로비`

- Roblox 서버는 최대 4명, **각 플레이어의 전투는 서로 독립**. 협동/PvP 아님. 소유자 외 전투 정보도 전송하지 않음.
- 한 전장, 한 논리 레인, 1차원 X 이동. 카메라·깊이·애니는 2.5D 연출이다.
- 영웅 `wayfinder` 1종, 무기 스킬 `pulse` 1개. 기본 자동 평타 없음.
- 아군 `vanguard/slinger/bulwark`, 적 `scrapper/spitter/brute` 각 3종. 적 본진은 정적 목표물이며 네 번째 적 유닛이 아니다.
- 스테이지 `s01/s02/s03` 모두 본진 파괴. 원작 1-1/1-2/1-3의 직접 복제나 D모드 이식이 아님.

### 3.2 전투 규칙

1. 식량·마나 0, 각각 최대40/100, 기본 초당2 생성. 생존 중에만 생성하고 종결 시 중지한다.
2. 소환 버튼 3개: 비용10/20/30, 쿨타임1/2/4초. 신규 계정은 모두 L1 보유한다.
3. 아군은 오른쪽, 적은 왼쪽으로 전진. 최근접 전방 적이 사거리 안이면 멈추고 자동 공격한다. 몸 충돌/아군 밀어내기 없음.
4. `pulse`: 마나10, 쿨타임1.5초, 오른쪽으로 단일 적 관통 없는 탄 발사. 입력 순간 마나를 차감하고 취소/빗나감에도 환급하지 않음.
5. 영웅은 시전 중에도 이동 가능. 지원장 반경7.5stud, 아군 공격 피해×1.10. 랜덤 유닛 스킬·상태이상·방어력·크리·회피는 없음.
6. 영웅 HP≤0 패배, 적 핵 HP≤0 승리. **같은 tick 동시 파괴는 패배 우선**. 600초 초과가 아니라 **600초 도달 시** 시간초과 패배(그 tick 승패가 먼저).
7. 적이 X=0에 도달하면 영웅의 현재 X 바로 왼쪽으로 재배치해 재교전한다. 루프나 자의적 골드 페널티 없음. 경계 세부는 DATA_MODELS.
8. 동시 생존 한도 아군30/적40, 투사체128. 아군 한도면 소환 거부·무차감, 적 한도면 스폰 타이머를 동결한다.

수치는 전부 `mvp-proto-001`의 **플레이 검증 전 기준선**이다. 부록에서 유래한 HP/AP도 원작 난이도가 재현된다는 뜻은 아니다.

### 3.3 성장·저장

- 유닛은 골드로 L1→L5. 골드0 시작. 모든 아군이 기본 해금되어 유료 언락 없음.
- 영웅 L1→L10, 누적 EXP 곡선 `100×L²`; 한 번에 여러 레벨 상승 가능. 레벨마다 포인트1.
- 로비에서 체력/식량 재생/마나 재생 3개 특성에 각 최대3포인트. 새 경기부터 적용; 전투 도중 구매·분배 불가.
- 승리 시 처치 보상+스테이지 보상, 첫 승리 추가 골드 지급. 패배/이탈/시간초과는 보상0. 처치 중 수치는 임시이며 저장 확정 전에는 소유 골드가 아니다.
- s01 승리→s02, s02 승리→s03. 별·퀘스트·장비·젬·부활·세이브 슬롯·중단 전투 복원은 MVP 제외.
- 한 DataStore profile key에 성장·화폐·해금·진행·실행 식별자를 같이 저장. 저장 실패 시 완료로 표시하거나 다음 전투에 진입하지 않음.
- 확인된 마지막 저장까지만 내구성을 보장한다. **결과 저장 이전 서버 강제 종료의 미확정 보상은 잃을 수 있다.** 전투 재접속 이어하기는 제공하지 않는다.

## 4. 입력·UI 요구

| 동작 | PC | 모바일 |
|---|---|---|
| 좌/우 이동 | A/D 또는 ←/→, 양쪽 동시=정지 | 좌하단 좌/우 홀드 버튼, 양쪽 동시=정지 |
| 아군 1/2/3 소환 | 1/2/3 또는 클릭 | 하단 우측 3개 탭 버튼 |
| 무기 스킬 | Q 또는 클릭 | 우하단 큰 스킬 버튼 |
| 선택/성장/결과 | 포인터/키보드 포커스 | 탭 |

- 가로 화면 우선. 세로 화면도 버튼·결과 조작 가능하고 가로 전환 안내를 표시한다. 해상도별 전투 판정은 같음.
- 이동은 홀드, 소환/스킬은 누를 때 한 번만. 자동 연타 없음. 이동+스킬, 이동+소환의 멀티터치 가능.
- 메뉴·텍스트 입력·창 포커스 상실·터치 취소에서 이동0 전송, 서버도 마지막 이동 의도 수신 후0.5초면 자동 정지.
- HUD: 영웅/핵 HP, 식량·마나/상한, 비용·쿨다운·거부 이유, 전투 시간, 임시 보상, 저장 상태.
- 기본 터치 표적 최소48×48 UI offset 단위, 간격8. safe inset 존중. 색 외에 아이콘·문자·형태로 진영/상태 구분. 상세 입력 계층은 ARCHITECTURE.

## 6. 비기능 목표와 릴리스 중단선

아래는 플랫폼 보장이 아니라 프로젝트 목표다. 실제 측정 장치·Studio 빌드·샘플 길이는 TEST_PLAN에 기록한다.

- 서버20Hz, 복제10Hz, 4경기×(아군30+적40+영웅+핵), 경기당 탄128 스트레스에서 simulation tick p95≤10ms.
- 모바일 지정 Android 실기기에서 10분 p95 frame time≤33.3ms, PC≤16.7ms 목표. Studio device emulator만으로 성능 합격 처리 금지.
- RTT200ms 모의 환경에서 입력 ack p95≤350ms, 통신 회복 시 최신 snapshot 적용≤1초 목표.
- 저장 중복·타인 데이터 노출·잔액 음수·클라이언트 피해 신뢰가 재현되면 출시 차단. 성능 미달은 콘텐츠 상한/표현량을 낮추고 재측정한다.

## 7. 현재 완료 범위

이번 결과는 설계 문서와 구현 계획이다. Luau 게임, Rojo 프로젝트, 변환기, 테스트 harness, Studio MCP 연결 및 플레이 테스트 결과는 아직 없다. 제공 문서의 원본 APK/XML도 현재 작업 트리에 없다. 문서 정합성 검사와 실제 게임 검증을 혼동하지 않는다.
